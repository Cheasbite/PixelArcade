Purpose and Concept

PixelArcade is a retro arcade site where games play on the page. The look is inspired by classic arcade portals.

Audience

Casual players, and anyone reviewing this Web Development I project.

Technology

The site is HTML5 and CSS3 only. The pages contain no JavaScript. The games inside the frames run their own code.

How Embedding Works

An iframe shows another page inside ours. Lichess games load from lichess.org. 2048 and Hextris are open-source copies stored in this project.

Why Many Games Are Missing

Most .io games have no verified embed permission, so they are not included.
